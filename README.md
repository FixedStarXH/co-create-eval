# 人机协同创造力评测系统

一个面向教育创意任务的人机协同创作与评测项目。系统计划支持独立构思、AI 辅助创作、作品版本管理、匿名评分、个人报告和结构化数据导出。

## 当前状态

目前处于**分批实现阶段**。参与者、教师和管理员的主要页面已有前端原型；参与者凭证登录、演示版同意记录和两场任务分配已接入后端。作品持久化、真实模型连接、工作人员身份与评分等功能仍在开发计划中。界面截图和示例内容仅用于展示设计。

## 技术方向

前端：Vue 3、TypeScript、Vite。后端：Python、FastAPI。持久化：SQLModel + SQLite。AI 模型通过后端适配层接入，密钥只保存在服务器环境中。正式开发时依赖版本会在锁文件中固定。

## 开发路线

1. 完成参与者的任务、构思、编辑、提交与报告流程。
2. 接入真实 AI 对话及提交后的辅助评价。
3. 实现教师匿名评分、管理端和匿名数据导出。
4. 补齐测试、部署和故障恢复。真实用户数据和密钥不进入公开仓库。
