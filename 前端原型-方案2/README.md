# 方案 2：创作工作台前端原型

这是《人机协同创造力评测系统的设计与实现》的 **P04 创作工作台视觉与交互原型**。它依据选定的第 2 张效果图制作，采用蓝灰色专业写作界面：顶部五个作品章节、中央宽幅编辑器、底部 AI 建议栏。

## 运行

```bash
npm install
npm run dev -- --host 0.0.0.0 --port 4173 --strictPort
```

打开 <http://localhost:4173/>。生产构建检查：`npm run build`。

## 可以体验的操作

- 切换“目标、学生任务、活动流程、资源、评价”五个章节并编辑内容。
- 使用基础文字格式工具；展开任务要求；查看作品预览。
- 查看倒计时和保存状态，点击“保存草稿”。
- 展开或收起底部建议，选择“改写后采纳”或“暂不采纳”。采纳前可修改文字，确认后才会进入当前章节。
- 在窄屏查看页面；正式创作仍以桌面浏览器为基线。

## 当前边界

这是一个前端演示。章节内容只保存在当前页面内存中，刷新后会重置；“已保存”是演示反馈，没有数据库或恢复机制。倒计时是界面演示，不控制研究阶段。AI 建议使用预置示例，没有接入模型。提交、问卷、教师匿名评分和测评报告尚未实现。

正式系统开发时，须按[项目需求规格](../docs/requirements.md)补齐：独立构思阶段、条件分配、服务端保存与恢复、AI 对话和来源记录、提交锁定、教师评分、报告和匿名数据导出。本原型的交互演示不产生正式评测数据。
