# 全流程前端界面原型

该 Vue 原型采用蓝灰色文档工作台风格，覆盖参与者、评分教师和管理员的主要页面。可通过右上角“页面导航”直接查看各页面，也可从参与者入口按流程体验。

## 页面范围

- 参与者：进入与说明、任务说明、独立构思、创作工作台、作品提交、体验问卷、场次间休息和个人报告。
- 工作人员：角色登录、匿名待评列表和教师评分。
- 管理员：运行概览、任务配置、参与进度和数据导出。
- 创作工作台包含两场任务的界面差异、AI 示例对话、建议采纳、目标章节选择、章节编辑和作品预览。

## 运行与检查

```bash
npm install
npm run dev -- --host 127.0.0.1 --port 4173 --strictPort
npm run build
```

先按[后端说明](../backend/README.md)启动服务并创建本地演示参与者，再在浏览器打开 <http://127.0.0.1:4173/>。参与者入口使用创建的编号和凭证；工作人员入口仍只用于界面预览。

在本机有 Chrome、前后端服务运行且已创建 S1 演示参与者时，将 `QA_STUDY_CODE` 和 `QA_CREDENTIAL` 设为该参与者的编号和凭证，再执行 `node scripts/qa-pages.mjs`。脚本中的 Chrome 路径按 Windows 默认安装位置设置，凭证不应提交到仓库。

## 原型边界

参与者凭证、演示版同意记录及两场任务分配已接入后端，首场任务从服务读取；第二场衔接与后续创作仍为预览。其他页面使用内存和示例数据，刷新会重置。计时和作品保存状态为演示，工作人员账号尚未接入身份验证。AI 对话是明确标注的示例回复，提交、评分、配置与导出尚未连接后端或数据库；详见[项目需求规格](../docs/requirements.md)。
